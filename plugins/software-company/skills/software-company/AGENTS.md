# Software Company 技能

## 用途

- 讓 Codex 在一個 App 工作階段與工作區完成軟體專案規劃與交付。

## 責任範圍

- `SKILL.md` 定義模式選擇與授權範圍。`references/plan.md` 定義規劃產物，`references/delivery.md` 定義交付及審查，`references/boss.md` 定義從需求開始的全流程。

## 本地契約

- `plan` 依序寫出 `prd.md`、`system-design.md`、`task-list.md`，驗證需求對應後停在規劃階段。
- `generate` 依完整的既有計畫及任務順序接續已授權的實作。缺少計畫時停止並指出欠缺文件。
- `boss` 可用一項具體交付需求完成規劃、實作、測試及審查。流程在同一聊天接續，遵守工作區範圍及必要核准。
- 測試與審查分別輸出 `test-report.md` 和 `review.md`，審查亦可依使用者要求只在聊天回報。
- 角色是在目前 App 工作階段執行的流程步驟。模型與工具由 Codex App 管理。

## 工作指引

- 變更階段、授權或產物時同步檢查技能入口、參考文件及 README。

## 驗證

- 在 Windows Codex App 的本機工作區以攝氏轉華氏案例驗證三份規劃文件、需求交接及 `plan` 停止範圍。
